# 🚌 知途实时公交 (ZhiTu Bus Radar)

**全城公交实时位置 · 快到站震动提醒** —— 一款轻盈、无广告、支持全国 **486 个城市** 的安卓实时公交看板与到站盯梢工具。

---

## ✨ 核心特性

1. **按站点聚合的常用看板（不预置冗余路线）**
   - 遵循「**先找公交站台 → 勾选本站常坐的几路公交**」的高效通勤逻辑，看板按**城市 + 公交站台**自动分组聚合（例如在同一站台下同时查看 24路、41路、104路 的实时倒计时）。
   - 对于偶尔一次的临时出行，直接在顶部搜索框或「附近站点」点开线路即可**临时查看全线车况**，不会污染常用看板。

2. **纵向实景小巴士路线图**
   - 点开任意公交线路即可展开纵向全线站牌轴：
     - **左侧专属小巴士车道**：实时绘制矢量蓝色小巴士，区分**「已到站」**（停靠在站点圆环旁）与**「行驶中」**（位于两站连线正中间，并高亮当前行驶路段为暖橙色）。
     - **候车站牌标识与地铁换乘**：当前候车站显示为蓝底白边圆形公交站牌图标，支持点击任意站点切换候车站、一键**返程换向**（内置单行道同路口不同站名智能匹配）、查看**首站发车时刻表**与**本站全部途经线路**。
     - 沿线地铁换乘站自动按官方线路色系展示柔和浅色换乘标签（如 `1号线`、`2号线`、`12号线`、`13号线` 等）。

3. **通知栏快到站震动盯梢（前台服务保活）**
   - 等车期间开启「到站提醒」，App 会在系统通知栏常驻每 **15 秒**自动刷新的实时状态条（显示剩余站数、距离米数、预计到站分钟数）。
   - 当车辆距离候车站 **≤ N 站** 或 **≤ M 分钟**（可在设置中自由调节，默认 2 站 / 3 分钟）时，自动触发高优弹窗与双震动提醒；车辆到站后可一键「已上车/停止」或到站 2.5 分钟后自动结束盯梢，绝不后台遗留耗电。
   - 支持 **夜间免打扰（23:00 - 07:00）** 与 **省电白名单一次性授权检测**。

4. **全国 486 城无缝切换 + GPS 跨城自动识别**
   - 支持一键切换全国 **486 个城市**（覆盖上海、北京、杭州、苏州、南京、广州、成都、武汉、重庆、无锡、宁波、西安、长沙、青岛、天津等），内置拼音/汉字实时检索与 20 个热门城市快捷面板。
   - 去到外地点击 **「GPS校准 / 自动识别所在城市」**，原生定位自动完成 **WGS-84 转 GCJ-02 火星坐标校准** 并切换至当前城市公交库。
   - **跨城看板共存**：每条常用路线独立保存所属城市的 `cityId`，即使切换了当前浏览城市，看板上不同城市的常用路线依然各自独立同步实时车况。

5. **都市蔚蓝 + 柠檬暖黄磨砂视觉 & 日夜双主题**
   - 采用清爽高辨识度的**都市蔚蓝（Urban Azure）+ 柠檬暖黄（Lemon Gold）**半透明磨砂玻璃（Glassmorphism）设计，搭配 **19:00 - 06:00 自动切换的「深海星蓝」夜间模式**。
   - 断网与弱网防变形保护：底层异常统一清洗为简短中文状态并锁定倒计时区宽度，任何屏幕尺寸与飞行模式下界面均稳固不折行。

## 🔗 数据来源与接口说明

- **全国实时公交引擎**：`https://web.chelaile.net.cn/api/`（含 `encryptedLineDetail.action` 全线车辆位置、`encryptedNearlines.action` 周边站点、`encryptedStnDetail.action` 同站多线、`clientSearch.action` 站点线路检索、`depTimeTable.action` 首站时刻表；内置 `webapp_alipay_fuwu` 与 `webapp_meizu_map` 双授权通道容灾切换）。
- **全国城市目录与 GPS 城市识别**：`https://web.chelaile.net.cn/wwd/ncitylist`
- **跨城定位与地理编码**：Android 原生 `LocationManager` + `Geocoder`（内置 WGS-84 → GCJ-02 坐标转换）+ 和风天气全国 GeoAPI（`https://mk487vpakf.re.qweatherapi.com/geo/v2/city/lookup`）兜底。

## 🛠️ 本地编译与打包

本项目使用轻量免 Gradle 守护进程的便携式构建脚本（复用 JDK 17 与 Android Build Tools 34 `aapt2` / `d8` / `zipalign` / `apksigner`）：

```bash
bash build_apk.sh
```

执行后会自动将 `assets/` 下的模块化 CSS/JS 内联打包为单文件 `index.html`，并编译输出通过 v2/v3 签名校验的 **`知途实时公交.apk`**。
